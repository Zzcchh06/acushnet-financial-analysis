# Acushnet Holdings Corporation - Financial Statement Analysis
Project Overview
An Indpendent financial statement analysis of Achusnet Holdings Corporation, the parent company of Titleist, using publicly available financial reporting data. 

Objectives
- Analyze the company's financial performance and position.
- Organize financial statement data in Microsoft Excel.
- Evaluate financial trends and key financial ratios.
- Present findings in a dashboard for easier interpretation.

Project Components
- Raw financial data
- Income statement analysis
- Balance sheet analysis
- Cash Flow Statement analysis
- Financial ratio analysis
- Excel Dashboard

Tools & Skills
- Microsoft Excel
- Financial statement analysis
- Financial ratio calculations
- Data organization and visualization
- Public company 10-K research

Data Source
Acushnet Holdings Corp. annual reports and form 10-K filings.
